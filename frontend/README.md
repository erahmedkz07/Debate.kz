# Debate.kz — frontend

Веб-интерфейс платформы для дебатных турниров (формат WSDC). Сейчас работает **на тестовых данных**, без бэкенда.

## Стек

React 19 · Vite 8 · TypeScript · Tailwind CSS 4 · React Router 7 · framer-motion · react-i18next (RU/KZ) · react-hook-form + zod · Radix UI (Dialog, Select, Dropdown, Tabs) · lucide-react · sonner

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + production-сборка в dist/
```

## Страницы

| Путь | Что это |
|---|---|
| `/` | Главная |
| `/tournaments` | Список турниров: поиск, фильтры, сортировка, пагинация |
| `/tournaments/:id` | Публичная страница турнира: обзор, команды, жеребьёвка, результаты, спикеры, судьи |
| `/rating` | Рейтинг команд и спикеров |
| `/about`, `/pricing` | О платформе, тарифы + FAQ |
| `/login`, `/register` | Вход и регистрация (без выбора роли, с согласием на обработку данных) |
| `/verify-email?token=…` | Подтверждение email по ссылке из письма |
| `/forgot-password`, `/reset-password?token=…` | Восстановление пароля по ссылке из письма |
| `/invite/:token` | Приглашение судьёй или соорганизатором турнира |
| `/me` | Профиль: фото, мои заявки, мои дебаты, настройки |
| `/dashboard` | Мои турниры (создать может любой пользователь) |
| `/dashboard/tournaments/new` | Мастер создания турнира (турнир уходит на модерацию) |
| `/dashboard/tournaments/:id/:section?` | Управление: заявки, команды, судьи (приглашение по ссылке), раунды, жеребьёвка, бюллетени, результаты, настройки |
| `/judge` | Судейство: назначения и история (раздел появляется после приглашения) |
| `/ballot/:debateId` | Бюллетень (судья состава или организатор; проверяет сервер) |
| `/admin` | Админ-панель: модерация турниров, оплата Pro, пользователи, назначение ответственных за безопасность — только админ |
| `/motions` | Банк тем с поиском и фильтрами |
| `/timer` | Таймер речей для WSDC, BP, АПФ и Карла Поппера: сигналы, окно вопросов, льготные 15 секунд, экран не гаснет |
| `/tournaments/:id/projector` | Режим проектора для зала: обложка, тема с отсчётом подготовки, жеребьёвка |
| `/checkin/:tournamentId` | Чек-ин команды по QR с экрана в зале |
| `/verify/:code`, `/certificates/:code` | Проверка подлинности сертификата, печать/PDF сертификата |
| `/teammates` | Поиск сокомандника (контакты не публикуются) |
| `/safety` | Сообщить о поведении (можно анонимно), статус своих обращений |
| `/safety/reports` | Очередь обращений — админы и ответственные за безопасность |
| `/notifications` | Центр уведомлений |
| `/clubs`, `/clubs/:id`, `/clubs/join/:code` | Каталог клубов, страница клуба (общая для всех членов), вступление по ссылке |
| `/tools` | Материалы: все инструменты и справочные страницы |
| `/formats` | Форматы: WSDC, BP, АПФ, Карл Поппер (данные — `src/content/formats.ts`) |
| `/reference` | Справочник: словарь, критерии судейства, советы |
| `/calculator` | Калькулятор баллов по форматам |
| `/news`, `/news/:id` | Новости (админы пишут и публикуют) |

Публичные страницы видны всем. Действия требуют входа: гостя отправляет на `/login?next=…` и после входа возвращает обратно.
Глобальные роли — только `user` и `admin`; организатор и судья — права внутри турнира (подробно в `backend/README.md`).
Демо-аккаунты — в `backend/README.md`.

## Структура

```
src/
  api/          # ЕДИНСТВЕННАЯ точка доступа к данным (fetch к Express API)
  mocks/        # тестовые данные и ссылки на фото (Unsplash)
  types/        # типы, повторяют схему БД
  locales/      # ru.json, kz.json — все тексты интерфейса
  components/   # ui/ (кнопки, поля, диалоги…), layout/, brand.tsx (логотип, орнамент)
  pages/        # страницы, dashboard/ — кабинет организатора
public/brand/   # SVG-логотипы
```

## Как подключить бэкенд

Компоненты не импортируют `mocks/` напрямую — только функции из `src/api/index.ts`.
Чтобы перейти на Express API, достаточно заменить тела этих функций на `fetch()`;
страницы менять не нужно.

## Бренд

- Основной цвет `#009BC9`, акцент `#FFDE00` — CSS-переменные в `src/index.css` (есть тёмная тема).
- Орнамент «қошқар мүйіз»: компоненты `Ornament` и `OrnamentPattern` в `src/components/brand.tsx`.
- Жёлтый не используется для текста на белом фоне (плохой контраст).

## Офлайн-бюллетени (PWA)

Wi-Fi на площадке пропадает как раз в конце раунда, поэтому бюллетень не должен зависеть от сети:

- пока судья вводит баллы, форма сохраняется на устройстве (`src/lib/ballotOutbox.ts`) и восстанавливается после перезагрузки;
- открытый хотя бы раз бюллетень открывается без сети — из сохранённой копии;
- если отправить не удалось из-за сети, бюллетень встаёт в очередь и уходит сам, когда связь вернётся
  (`src/components/offline/OfflineSync.tsx`: событие `online` + повтор раз в 30 секунд). Повторная отправка безопасна —
  сервер заменяет прежний бюллетень того же судьи;
- при недоступном API страница помнит вошедшего пользователя (только имя, email и роль — без телефона),
  чтобы судью не выбрасывало на вход; сам доступ по-прежнему проверяет сервер.

Service worker собирается при `npm run build` из `service-worker.js` (плагин в `vite.config.ts` добавляет список
файлов сборки) и кладётся в `dist/sw.js`. Регистрируется только в production-сборке; `/api` и `/uploads` не кэширует.
Проверить локально: `npm run build && npm run preview`.
